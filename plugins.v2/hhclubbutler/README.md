# 憨憨保种区管家（MoviePilot 插件）

<img src="https://github.com/SixOrg.png" width="48" height="48" align="left" style="border-radius:50%;margin-right:10px;" alt="六个橙子" />

作者：**六个橙子**（[GitHub](https://github.com/SixOrg)）

## 功能

- 自动抓取憨憨保种区（rescue.php）全部页面的种子
- **增量优选**：不删除已做种任务，补齐达标（目标积分/目标体积二选一），可选「做种人数」条件过滤候选
- **换种优选**：从高倍率到低倍率逐档构建保种集合（同档位不替换），优先用高倍率候选替换低倍率已保种，保证达标且尽量少用低倍率种子；被换出的种子删除任务+文件，高倍率候选自动推送下载
- 一键推送到 MoviePilot 已配置的 QB/TR 下载器，保存路径、自定义标签
- **今日保种概况**：完成页 ∩ 下载器做种交集统计（在保种子/体积/达标可得憨豆积分/人数分档），支持 MP 仪表盘卡片 + 数据页展示
- **安全防护**：当前保种信息获取失败时自动中止运行（防止误推送）；推送前过滤已在下载器的种子（含下载中的，防止重复添加）；无法自动获取站点UID时停止运行（绝不回退默认UID，防止误用他人账号）
- **兼容性**：兼容 MoviePilot v2 下载器返回的 dict 形态种子数据（tracker 字段多属性兼容读取）

## 安装（GitHub 插件市场）

1. 打开 MoviePilot Web UI → 「设置」→ 插件市场 → **添加仓库**，填入：
   ```
      https://github.com/SixOrg/MoviePilot-Plugins
         ```
            （或环境变量 `PLUGIN_MARKET` 追加该地址，多个地址逗号分隔）

            2. 进入「插件」页面 → 刷新插件市场 → 找到「憨憨保种区管家」→ 安装并启用。

            ## 站点信息（自动获取为主）

            插件从 **MoviePilot「设定 → 站点」** 自动读取憨憨站的 **Cookie / UA / 站点地址**（按域名匹配 hhanclub / hhclub），并自动访问站点主页解析 **站点UID**。只要在 MP 站点管理里添加过憨憨站，无需任何手动配置。

            **站点UID**：留空自动获取；若自动获取失败（站点主页访问超时等），插件会停止运行并在日志提示——请在配置中手动填写自己的 UID，绝不回退到任何默认 UID（默认值属于他人账号，误用会拉错完成列表）。

            ## 公式（经结算日志 + Excel 达标池 109 项交叉验证）

            ```
            每日憨豆 = 0.018467 × 体积(GB) × 18h × 憨豆倍率
            每日积分 = 0.018195 × 体积(GB) × 18h × 积分倍率
            ```

            倍率按**初始做种人数**（保种区种子当前做种人数即下载时人数）：

            | 初始人数 | 憨豆倍率 | 积分倍率 |
            |---------|---------|---------|
            | 0-1人   | ×3      | ×2      |
            | 2-3人   | ×2      | ×1.75   |
            | 4-5人   | ×1.5    | ×1.5    |
            | >5人    | 无奖励  | 无奖励  |

            ## 配置说明

            | 配置项 | 说明 |
            |-------|------|
            | 优选模式 | 增量优选（默认）/ 换种优选 |
            | 目标类型 | 下拉二选一：按目标积分 / 按目标体积（**切换即时生效**） |
            | 目标积分（每日） | 默认1800；站点上限1800，超过1800的配置保存后自动纠正为1800，运行硬性锁定 |
            | 目标体积（GB，总保种上限） | 含已做种总体积，0=不限 |
            | 做种人数 | 过滤条件：支持单值或区间，如`1`或`1-5`，留空=系统自行优选 |
            | 站点UID | 留空自动获取，自动获取成功自动回填并保存；失败时必须手动填写，否则停止运行 |
            | 排除0做种人数 | 勾选后不优选0做种人种子 |
            | 下载器 | 选择 MoviePilot 中已配置的 QB/TR |
            | 保存路径 | 下载器中的保存目录，留空用下载器默认 |
            | 自定义标签 | 推送后自动给种子打标签（QB=tag，TR=labels） |
            | 执行周期 | cron格式，默认每天14:30（保种区14:10更新后） |

            ## 注意事项

            - 换种优选会**删除下载器中的任务并删除对应文件**（释放硬盘空间），请确认后再启用
            - MP 站点管理里的 Cookie 过期后，需在 MP「站点」页面更新
            - 保种区每天下午14:10左右更新（做种人数<5的种子移入），建议执行周期设在14:30之后
            - 当前保种统计只计**已下载完成（进度100%）**的种子，下载中的不计入
