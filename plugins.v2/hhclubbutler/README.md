# 憨憨保种区管家（MoviePilot 插件）

<img src="https://github.com/SixOrg.png" width="48" height="48" align="left" style="border-radius:50%;margin-right:10px;" alt="六个橙子" />

作者：**六个橙子**（[GitHub](https://github.com/SixOrg)）

## 功能

- 自动抓取憨憨保种区（rescue.php）全部页面的种子
- **增量优选**：不删除已做种任务，补齐达标（目标积分/目标体积二选一），可选「做种人数」条件过滤候选
- **换种优选**：从高倍率到低倍率逐档构建保种集合（同档位不替换），优先用高倍率候选替换低倍率已保种，保证达标且尽量少用低倍率种子；被换出的种子删除任务+文件，高倍率候选自动推送下载
- **自动清理未完成下载**：可设置 N 天，自动删除超时仍未完成的本站下载任务（含未完成文件），避免半成品占盘
- 一键推送到 MoviePilot 已配置的 **QB / TR** 下载器，支持保存路径、自定义标签
- **保种区概况**：完成页 ∩ 下载器做种交集统计（在保种子/总体积/达标可得憨豆积分/达标可得积分/初始做种人数分档），支持 MP 仪表盘卡片 + 数据页展示；每 6 小时自动刷新一次，也可手动立即刷新
- **安全防护**：当前保种信息获取失败时自动中止运行（防止误推送）；推送前过滤已在下载器的种子（含下载中的，防止重复添加）；自动获取站点 UID 失败时停止运行（绝不回退默认 UID，防止误用他人账号）

## 安装（GitHub 插件市场）

1. 打开 MoviePilot Web UI → 「设置」→ 插件市场 → **添加仓库**，填入：
   ```
   https://github.com/SixOrg/MoviePilot-Plugins
   ```
   （或环境变量 `PLUGIN_MARKET` 追加该地址，多个地址逗号分隔）

2. 进入「插件」页面 → 刷新插件市场 → 找到「憨憨保种区管家」→ 安装并启用。

## 站点信息（全自动，无需手动配置）

插件从 **MoviePilot「设定 → 站点」** 自动读取憨憨站的 **Cookie / UA / 站点地址**（按域名匹配 hhanclub / hhclub），并自动访问站点主页解析 **站点 UID**。只要在 MP 站点管理里添加过憨憨站，无需任何手动配置，UID 自动获取并回写缓存。

若自动获取失败（站点 Cookie 过期、站点主页不可达等），插件会停止运行并在日志提示——请检查 MP 站点管理里的憨憨站 Cookie/UA 是否有效，更新后重新运行即可。

## 公式（v1.3，经 9/12~9/16 四日结算真值回归，误差 ≤±0.4%）

保种区结算采用 **A 份额模型**（wiki 公式，B 只调一次，按各档 A 占比分配）：

```
Aᵢ = (1 − 10^(−Tᵢ/8)) × Sᵢ × (1 + 2×10^(−(Nᵢ−1)/9))
憨豆 B₀ = 31.5 / 积分 B₀ = 30.5（B0=25 已被数学证伪：atan 上限决定日上限≈1730，达不到实结 1863）
每日憨豆 = B × (档位A占比 × 憨豆倍率) × 18h
每日积分 = B × (档位A占比 × 积分倍率) × 18h，上限 1800（站点实测）
```

- Tᵢ = 种子发布到现在的周数，Sᵢ = 体积(GB)
- Nᵢ = **当前做种人数**（人数因子按 now）；档位倍率按**下载时做种人数**（init）
- 保种区额外奖励上限 1800 积分（插件目标积分硬锁）
- 四日验证：9/12→1829/1564、9/13→1835/1568、9/15→1865/1594、9/16→1863/1593，误差 −0.03%~+0.40%

倍率按**下载时做种人数**（wiki 原文）：

| 下载时人数 | 憨豆倍率 | 积分倍率 |
|---------|---------|---------|
| 1人     | ×3      | ×2      |
| 2-3人   | ×2      | ×1.75   |
| 4-5人   | ×1.5    | ×1.5    |
| >5人    | 无奖励  | 无奖励  |

> 注：>5 人种子会定期移出保种区（每天 14:10 更新时移入低人数种子）。

## 配置说明

| 配置项 | 说明 |
|-------|------|
| 发送通知 | 勾选后每次运行完成推送结果（企微/Telegram/站内信等，按 MP『消息通知』配置渠道分发） |
| 优选模式 | 增量优选（默认）/ 换种优选 |
| 目标类型 | 下拉二选一：按目标积分 / 按目标体积（**切换即时生效**） |
| 目标积分（每日） | 默认 1800；站点上限 1800，超过 1800 的配置保存后自动纠正为 1800，运行硬性锁定 |
| 目标体积（GB，总保种上限） | 含已做种总体积，0=不限 |
| 做种人数 | 过滤条件：支持单值或区间，如`1`或`1-5`，留空=系统自行优选 |
| 排除0做种人数 | 勾选后不优选 0 做种人种子 |
| 下载器 | 选择 MoviePilot 中已配置的 QB/TR |
| 保存路径 | 下载器中的保存目录，留空用下载器默认 |
| 自定义标签 | 推送后自动给种子打标签（QB=tag，TR=labels） |
| 自动清理未完成下载（天） | 本站相关的未完成下载任务超过 N 天仍未完成时，自动删除任务+文件；0=不启用 |
| 执行周期 | cron 格式，默认每天 14:30（保种区 14:10 更新后） |

## 注意事项

- 换种优选会**删除下载器中的任务并删除对应文件**（释放硬盘空间），请确认后再启用
- MP 站点管理里的 Cookie 过期后，需在 MP「站点」页面更新
- 保种区每天下午 14:10 左右更新（做种人数<5 的种子移入），建议执行周期设在 14:11
- 当前保种统计只计**已下载完成（进度 100%）**的种子，下载中的不计入
- 保种区概况**每 6 小时自动刷新一次**（距最近一次运行或定时更新后开始计时，仅刷新数据，不优选/不推送/不删除）；数据页也可点击**「🔄 立即刷新」**手动更新
- 换种优选删除种子后，概况卡片会自动从快照中扣减已删种子的数量/积分/体积/做种分布，无需等待下次全量刷新
