# 憨憨保种区管家（MoviePilot 插件）

<img src="https://github.com/SixOrg.png" width="48" height="48" align="left" style="border-radius:50%;margin-right:10px;" alt="六个橙子" />

作者：**六个橙子**（[GitHub](https://github.com/SixOrg)）

## 功能

- **自动抓取憨憨保种区（rescue.php）全部种子**
- **增量优选**：不删除已有保种任务，按目标体积自动补齐缺量种子
- **换种优选（删低档位&补高档位）**：删除低档位种子、补充高档位种子（跨档位升级）
- **档位策略**：按初始做种人数分档（0-1人 / 2-3人 / 4-5人），高倍率替换低倍率
- **自动清理未完成下载**：可设置 N 天，自动删除超时仍未完成的本站下载任务
- **保种管理器**：独立网页工作台，支持批量删除、搜索、档位筛选、列自定义、多皮肤切换
- **站点∩下载器交叉匹配**：确保只操作真实在保种子
- **上次憨豆/上次积分展示**：面板显示 0 点结算的收益结果
- **数据面板**：当前保种数量/总体积/目标体积/各档位分布，每 6 小时自动刷新（顺带拉取并保存当日结算日志，两处憨豆/积分同源一致）
- **结算统计表**：独立页面展示近 30 日憨豆/积分实结柱状图、累计憨豆/积分左右双环仪表、近 12 月逐月实结滚动明细，翻页拉取结算日志并本地累计，每日仅拉取一次
- **Hosts 加速**：开启并配置 IP 域名（每行一条）后写入系统 hosts，加速憨憨站或需要加速的其他站点；关闭开关或清空配置自动还原；错误条目不写入（参考 thsrite「自定义Hosts」插件，见文末致谢）
- **消息推送**：运行完成推送在保数量、各档位分布及上次结算憨豆/积分

## 安装（GitHub 插件市场）

1. 打开 MoviePilot Web UI → 「设置」→ 插件市场 → **添加仓库**，填入：

   ```
   https://github.com/SixOrg/MoviePilot-Plugins
   ```

2. 进入「插件」页面 → 刷新插件市场 → 找到「憨憨保种区管家」→ 安装并启用。

## 站点信息（全自动，无需手动配置）

插件从 MoviePilot「设置 - 站点」自动读取憨憨站的 Cookie / UA / 站点地址（按域名匹配 hhanclub / hhclub），并自动访问站点主页解析站点 UID。只要在 MP 站点管理里添加过憨憨站，无需任何手动配置，UID 自动获取。

若自动获取失败（站点 Cookie 过期、站点主页不可达等），插件会停止运行并在日志提示——请检查 MP 站点管理里憨憨站的 Cookie/UA 是否有效，更新后重新运行即可。

## 配置说明

| 配置项 | 说明 |
|--------|------|
| 发送通知 | 勾选后每次运行完成推送结果（企微/Telegram/站内信等） |
| 优选模式 | 增量优选 / 换种优选（删低档位&补高档位） |
| 目标体积（GB） | 总保种体积目标，0=不限 |
| 管理下载器（多选） | 统计/优选/管理/删除覆盖所选下载器（可多选，支持 QB/TR 多容器混用） |
| 推送下载器（单选） | 新增任务的下载器，默认=管理下载器第一个 |
| 保存路径 | 推送下载器使用的保存目录，可填任意盘符路径（严格按此路径落盘，不再被下载器自动管理覆盖），留空用下载器默认 |
| 自动清理未完成下载（天） | 本站相关的未完成下载任务超过 N 天仍未完成时，自动删除任务+文件；0=不启用 |
| 执行周期 | cron 格式，默认每天定时运行 |
| Hosts 加速 | 开关 + 配置（IP 域名，每行一条）；开启并填写可加速站点（支持配置其他站）；关闭开关或清空配置自动还原；错误条目不写入 |

## 保种管理器

点击面板中的「保种管理器」按钮，新窗口打开独立工作台：

- 种子列表：ID、名称、大小、初始人数、当前人数、档位、完成时间、上次结算时间、今日做种时间、今日达标状态、来源下载器
- 表头点击排序、列宽拖拽、列显隐自定义（浏览器本地持久化）
- 搜索、档位筛选、批量删除（同步删除对应下载器任务及文件，按种子来源下载器定位）
- 多皮肤切换（下拉直达，设置本地持久化）
- 加载过程显示实时读秒与进度条提示


## 结算统计表

点击面板中的「结算统计表」按钮，新窗口打开独立页面：

- 近 12 个月每月憨豆 / 积分实结柱状图（数据标签与图形同色，来源：保种结算日志，每日 0 点实结）
- 累计憨豆 / 积分左右双环仪表（左环憨豆橙、右环积分青，中央显示累计数值）
- 近 30 日收益表：按结算日志逐日实结滚动明细
- 数据获取：概况每 6 小时刷新时顺带拉取并保存（每日一次，当日命中缓存后不再重复请求）；结算日志按时间正序分页，翻页全量拉取并按月聚合（最新一条取末页，兼容多页）；拉取失败或站点当日记录未生成时，每 5 分钟自动重试一次、当日累计最多 3 次，页面明确标注数据日期与获取状态；本地数据原子写入，杜绝空文件导致重复拉取
- 加载过程显示实时读秒与进度条提示

## 注意事项

- **换种优选会删除下载器中的任务并删除对应文件（释放硬盘空间）**，请确认后再启用
- 保种区每天下午 14:10 左右更新，建议执行周期设在更新之后
- MP 站点管理里的 Cookie 过期后，需在 MP「站点」页面更新
- 保种区规则：做种人数超过 5 的种子会被定期移出保种区
- Hosts 加速：容器部署更新的是容器内 /etc/hosts（非宿主机）；IP 填写错误会导致站点不可达，请谨慎填写；卸载插件前建议先关闭 Hosts 加速开关以便自动还原
