# 一键优选hosts（MoviePilot V3 插件）

测试站点 hosts 优选 IP：自动读取 MoviePilot 已配置站点，使用 [CloudflareSpeedTest](https://github.com/XIU2/CloudflareSpeedTest)（cfst）对全部 Cloudflare IP 段一次测速，优选出全局最优 IP 统一写入所选站点的系统 hosts；**关闭插件后 hosts 不生效（恢复为原始内容），重新开启插件即恢复生效**。支持自定义站点直接写入指定 IP。

## 功能

1. **目标站点**：自动读取 MP 已配置（启用）站点，支持逐站勾选、全选、反选；选中后在面板内以标签列出站点名称。未勾选任何站点时不写入。
2. **全局优选**：对全部 Cloudflare IP 段（官方 ip.txt）延迟 + 下载测速一次，取全局最优 IP 写入全部所选站点，并展示该 IP 的延迟与下载参数。
3. **自定义站点**：每行一个「IP 域名」（空格分隔），直接写入 hosts，不参与测速；若自定义域名与目标站点重复，保存时会提示冲突。
4. **统一写入**：所有优选结果写入系统 hosts 的插件管理区块（`# === 一键优选hosts START ===` 至 `# === 一键优选hosts END ===`），重复运行自动替换旧区块。
5. **关闭不生效 / 开启生效**：关闭插件即恢复备份的原始 hosts（hosts 不再生效）；重新开启插件时自动用上次写入明细重建管理区块，开启即生效。插件启用状态下如需主动清空，可用配置页「写入查看 → 清空写入」。
6. **运行方式**：顶部「立即运行」开关开启后保存设置即立即运行一次全局优选，或按定时频率自动运行。

## 安装

1. 将 `plugins.v3/yijianhosts/` 目录放入本地插件仓库 `plugins.v3/` 下，并把 `package.v3.json` 中的 `YijianHosts` 条目合并进仓库根目录的 `package.v3.json`。
2. 在 MoviePilot「插件市场 → 本地插件源」中刷新并安装「一键优选hosts」。

## 使用说明

点击插件卡片直接进入配置界面（Vue 联邦页面，与「自动更新tracker」同模式）。

- **启用插件 / 发送通知 / 立即运行**：界面顶部状态卡片内三个控件，样式与点选逻辑一致（点击所在区域即可切换）；「立即运行」为开关，开启后点击「保存设置」即保存配置并立即运行一次全局优选（若已有运行正在进行，会先终止旧任务再启动本次新的运行）。
- **写入查看 / 保存设置**：底部一行两个按钮；「写入查看」弹窗按 IP 分组展示写入明细（每组「IP：…」「写入站点：…」两行，不列域名），标题栏左侧提供「清空写入」按钮；「保存设置」保存后自动关闭配置界面并生效。
- **定时运行**：填写 cron 表达式（如 `0 4 * * *` 每天 4 点），支持快捷预设。
- **目标站点**：点击折叠面板展开后逐站勾选（紧凑网格）；面板内容顶部为提示「全局优选后写入hosts的站点」与「全选 / 反选」工具条；勾选后以标签列出所选站点名称；未勾选任何站点则不写入。
- **自定义站点**：每行一个，格式 `IP 域名`，例如：
  ```
  1.2.3.4 example.com
  5.6.7.8 another.com
  ```
  若自定义域名与目标站点（已勾选）重复，页面会实时提示，保存时后端也会校验提示冲突。
- **保存设置**：底部「保存设置」按钮，保存后自动关闭配置界面并生效。

## cfst 下载与网络说明

- cfst 由插件在首次运行（或首次触发优选）时自动从 GitHub Releases 下载，无需手工放置。
- 下载地址：`https://github.com/XIU2/CloudflareSpeedTest/releases/latest/download/`，按当前系统/架构自动选择（linux/windows/darwin × amd64/arm64/arm）。
- 国内网络下载失败或过慢时，在「高级设置 → cfst 下载镜像」填写镜像前缀（自动拼接到官方下载地址前）。推荐镜像依次尝试：`https://gh-proxy.com/`；`https://ghproxy.net/`（未一一列举，可自行前往 https://xiake.pro/github/ 获取更多）
  > 2026-11-03 实测：gh-proxy.com 最快、官方直连可用、ghproxy.net 可用但慢；其余常见镜像实测均不可用（证书错误/超时/错误页），若首选失效可切回官方直连。

## 注意事项

- 插件需要具备系统 hosts 文件的写权限（Docker 容器通常以 root 运行，可直接写 `/etc/hosts`；Windows 需以管理员运行 MoviePilot）。
- 首次写入前会自动备份原始 hosts；**关闭插件即恢复原始 hosts（不生效），重新开启自动重建生效**。
- 若直接卸载插件（未先停用），hosts 中的优选区块可能残留，重新安装后停用一次插件即可恢复。
- 运行完成通知采用分区模板：`[优选结果]`（全局最优 IP 及参数）、`[写入站点]`（目标站点名称，较多时简写为前 8 个 +「等 N 条」）、`[手动写入]`（自定义站点独立列出 IP 与域名）、`[失败项]`（有失败才出现）、`[运行概述]`。
- 高级设置参数：延迟上限（毫秒）、下载测速数量、下载速度下限（MB/s，低于下限视为未达标，0 表示不限制）、未达标重试次数与重试间隔（秒，测速未测出可用 IP 时按配置自动重试）、hosts 覆盖逻辑（「有结果即覆盖」或「结果更优覆盖」——后者仅当本次优选下载速度高于上次已生效结果时才覆盖）。
- 持久化说明：写入明细只在「本次确实写入成功」时刷新。因「结果更优覆盖」跳过、或测速失败导致的「写入 0 条」不会覆盖上次生效记录。Docker 容器重启会重建 `/etc/hosts`（插件管理区块随之消失），插件开启时会按生效明细自动重建；若重启后「写入查看」显示暂无区块，正常跑一次优选或重新保存设置即可恢复。

## 版本

- v1.1：修复容器重启后「hosts 写入情况」显示为空——写入 0 条的保留型运行不再覆盖生效明细（新增当前生效明细，与本次写入明细分离），插件开启时据生效明细自动重建 hosts 管理区块；写入查看改读生效明细，区块缺失时给出说明。其余功能与 v1.0 一致。
- v1.0：全局优选版——对全部 Cloudflare IP 段一次测速取全局最优 IP，统一写入所选站点（含延迟/下载参数展示，结果简化为一屏汇总）；未勾选站点不写入；支持自定义站点直接写入；立即运行改为开关（开启后保存即运行）；UI 重构（状态卡片、全选/反选工具条、已选站点标签、紧凑网格）；新增插件图标与「写入查看」分组明细弹窗；cfst 下载失败自动重试 3 次。
