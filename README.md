# MoviePilot-Plugins（第三方插件市场）

MoviePilot 第三方插件仓库，当前收录：

## 憨憨保种区管家

> 自动优选添加及换种工具/保种管理器/数据与等级/结算统计/Hosts加速

- **目标体积模式**：按总保种体积自动补齐，达标即止
- **增量优选**：不删已有保种，自动添加缺量种子
- **换种优选**：删除低档位种子、补充高档位种子（跨档位升级）
- **档位策略**：按初始做种人数分档（0-1 / 2-3 / 4-5），高倍率替换低倍率
- **保种管理台**：独立网页工作台，支持批量删除、列自定义、排序、筛选、多皮肤
- **站点∩下载器交叉匹配**：确保只操作真实在保种子
- **上次憨豆/上次积分展示**：面板显示 0 点结算的收益结果
- **数据面板**：当前保种数量/总体积/目标体积/各档位分布，每 6 小时自动刷新（顺带拉取并保存当日结算日志，两处憨豆/积分同源一致）
- **结算统计表**：独立页面展示近 N 月（默认 12）每月憨豆/积分实结柱状图、累计憨豆/积分左右双环仪表、近 N 日（默认 15）逐日实结滚动明细，翻页拉取结算日志并本地累计，每日仅拉取一次
- **数据与等级面板**：基础数据、四维达标雷达、等级阶梯、当前等级与下一级达标进度、预计升级用时；每日自动记录昨日全站憨豆/积分/上传增量及保种达标统计
- **Hosts 加速**：开启并配置 IP 域名（每行一条）后写入系统 hosts，加速憨憨站或需要加速的其他站点；关闭开关或清空配置自动还原；错误条目不写入（参考 thsrite「自定义Hosts」插件，见文末致谢）
- **消息推送**：运行完成推送在保数量、各档位分布及上次结算憨豆/积分
- [详情见插件文档](plugins.v2/hhclubbutler/README.md)

## 憨憨保种区明细导出

> 每天定时导出保种区种子明细为 CSV，用于数据积累与验证

- 默认每天 23:55 自动抓取「个人页面-完成的保种区种子」全部分页
- 导出 CSV：保种区明细全字段 + 分档统计
- 支持立即运行 / 插件命令 / API 手动导出与通知
- 可手动删除历史导出文件

## 无痕卸载

> 彻底卸载其他插件，删除配置、数据、代码和备份无残留

- **彻底卸载**：调用 MP 官方卸载流程 + 额外清理数据目录和备份目录
- **多选卸载**：设置页面下拉框多选，选择后保存即执行
- **无残留**：删除插件代码、配置、运行数据、数据库记录、备份文件

## 安装

MoviePilot → 设置 → 插件市场 → 添加仓库：

```
https://github.com/SixOrg/MoviePilot-Plugins
```

或环境变量：

```
PLUGIN_MARKET=https://github.com/SixOrg/MoviePilot-Plugins
```
