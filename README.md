# MoviePilot-Plugins（六个橙子的第三方插件仓库）

MoviePilot 第三方插件集合，由「六个橙子」开发维护。当前收录 5 个插件（V3 一个、V2 四个）。

## V3 插件

### 一键优选hosts（YijianHosts）v1.0

> CloudflareSpeedTest 全局优选后将所需站点写入 hosts / 支持手动自定义

- **全局优选**：对全部 Cloudflare IP 段一次测速，取全局最优 IP 统一写入所选站点 hosts（含延迟/下载参数展示）
- **手动自定义**：按「IP 域名」格式直接写入，独立于优选结果
- **开关即生效**：关闭插件自动恢复原始 hosts，重新开启自动重建
- **高级参数**：延迟上限、下载测速数量、速度下限、未达标重试、覆盖策略（有结果即覆盖 / 结果更优覆盖）
- **写入查看**：按 IP 分组明细，支持一键清空
- **消息推送**：运行完成按分区模板推送
- **定时 / 立即运行**：立即运行可终止旧任务重新开始
- [详情见插件文档](plugins.v3/yijianhosts/README.md)

## V2 插件

### 憨憨保种区管家（HHClubButler）v2.7

> 自动优选添加及换种工具 / 保种管理器 / 数据与等级 / 结算统计 / Hosts加速

- **目标体积模式**：按总保种体积自动补齐，达标即止
- **增量优选**：不删已有保种，自动添加缺量种子
- **换种优选**：删除低档位种子、补充高档位种子（跨档位升级）
- **档位策略**：按初始做种人数分档（0-1 / 2-3 / 4-5），高倍率替换低倍率
- **保种管理台**：独立网页工作台，批量删除、列自定义、排序、筛选、多皮肤
- **站点∩下载器交叉匹配**：只操作真实在保种子
- **数据面板**：保种数量/总体积/目标体积/档位分布，每 6 小时自动刷新
- **结算统计表**：近 N 月每月憨豆/积分柱状图、累计双环仪表、近 N 日滚动明细
- **数据与等级**：四维达标雷达、等级阶梯、升级进度、预计用时
- **Hosts 加速**：自定义 IP 域名写入系统 hosts，关闭自动还原
- **消息推送**：运行完成推送在保数量、档位分布及上次结算结果
- [详情见插件文档](plugins.v2/hhclubbutler/README.md)

### 憨憨保种区明细导出（HHClubDetailExporter）v1.0

> 每天定时导出保种区种子明细为 CSV，用于数据积累与验证

- 默认每天 23:55 自动抓取「完成的保种区种子」全部分页
- 导出 CSV：保种区明细全字段 + 分档统计
- 支持立即运行 / 插件命令 / API 手动导出与通知
- 可手动删除历史导出文件

### 飞书中文命令（feishuzhcmd）v1.2

> 飞书机器人自定义菜单支持全中文，中文菜单名映射 MP 标准命令

- **全中文菜单**：飞书自定义菜单不再需要 `/` 开头命令，直接用中文交互
- **渠道挂接**：拦截飞书入站消息，命中映射表即翻译为 MP 命令执行
- **未命中放行**：不影响订阅/搜索/洗版等 MP 原生自然语言交互
- **灵活映射**：配置页自定义「菜单名=命令」映射表，默认 14 条推荐
- **配置教程直达**：配置页顶部按钮一键打开《MP 飞书［中文菜单］交互配置教程》PDF（随仓库托管）
- **管理员白名单**：仅管理员可触发中文命令
- **兜底监听**：渠道挂接失效时仍可通过 UserMessage 事件翻译
- [详情见插件文档](plugins.v2/feishuzhcmd/README.md)

### 无痕卸载（CleanUninstall）v1.0

> 彻底卸载其他插件，删除配置、数据、代码和备份无残留

- **彻底卸载**：调用 MP 官方卸载流程 + 额外清理数据目录和备份目录
- **多选卸载**：设置页面下拉框多选，选择后保存即执行
- **无残留**：删除插件代码、配置、运行数据、数据库记录、备份文件

## 安装

MoviePilot → 设置 → 插件市场 → 添加仓库：

```
https://github.com/SixOrg/MoviePilot-Plugins
```

或环境变量：

```
PLUGIN_MARKET=https://github.com/SixOrg/MoviePilot-Plugins
```
